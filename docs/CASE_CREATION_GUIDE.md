# Case creation guide

## Before opening the form

Define one physical business location and the paid scope. Collect only known business facts; do not request passwords, OTPs, recovery codes, full personal IDs, or unnecessary financial records.

## Create the case

1. Enter the customer-facing business name, industry, preferred customer title/contact channel, expected completion time, and assigned administrator.
2. Write a short introduction explaining why the history is being organized and that unknown answers are acceptable.
3. Select the common module, one industry module, and only the issue modules supported by known context.
4. Enter prefilled facts with source type and a neutral source note. Mark whether the customer may correct them.
5. Add current Google Maps candidates without classifying them as duplicates or violations.
6. Add case-specific questions only when reusable modules do not cover the fact.
7. Select evidence categories needed for this case and explain masking requirements.
8. Review the customer preview before creating the case.

## Secure link

Creation returns a high-entropy link once. Copy it into the agreed private customer channel. Do not place it in a public document, shared spreadsheet, analytics parameter, or issue tracker. Regenerate it if sent to the wrong recipient; regeneration revokes the old link.

Suggested delivery message:

> 대표님, 같은 문제가 반복되지 않도록 과거 등록 흐름과 현재 사업장 정보를 먼저 함께 정리하려고 합니다. 정확히 기억나지 않는 내용은 잘 모르겠어요를 선택하셔도 됩니다. 아래 링크는 대표님 사건 전용이며 같은 링크로 임시 저장 후 다시 이어서 작성하실 수 있습니다.

Do not include claims that approval, restoration, verification, deletion, visibility, ranking, or ownership transfer is guaranteed.

## Before submission

The administrator may edit configuration and prefilled data while the case is not submitted. After final submission, preserve the original response and perform corrections only in normalized workspace fields. Reopen intake only when the customer needs to submit a revised response.
